# Contributing

This repository welcomes contributions in the following areas:

**Issues:** Open an issue for prior-art corrections, feedback on the mathematical formulation of DiSCo, empirical comparisons against the baselines described in the README, or any substantive critique of the framing. If you believe DiSCo or Pass-Conditioned Training appears in existing literature, please cite it specifically.

**Pull requests:** Welcome for documentation improvements, additions to `docs/related-work.md`, and implementation contributions in the `experiments/` directory. Keep PRs scoped, one thing per PR.

**Discussion issues:** If you want to collaborate substantively on the proposal itself (not just documentation), open a discussion issue rather than a PR. Architectural changes to the proposal should go through discussion before anyone writes code.

**Standards:** Be polite, be specific, and assume good faith. Vague objections are less useful than precise ones. If you think something is wrong, say what specifically is wrong and why.

For experimental code contributions: follow the conventions already in `experiments/` once that directory has content. Until then, open an issue first to discuss scope.
